| Sharpe 정의 | CAGR/변동성으로 계산 | 일간 초과수익률 평균/표준편차 × √252 |
| 중복 외부 검증·가짜 시간 | 캐시가 있어도 Yahoo `.info` 조회, 실행 시간 0.5 고정 | 캐시 우선 시세 로더로 존재 확인, 실제 소요 시간 |

납입과 체결의 의미는 다음과 같다.

- DCA 입력 금액은 회당 예산이다. 실제 시세가 있는 날 체결하면서 납입된 것으로 본다.
  휴장 중에는 같은 예정 회차를 보류하며, 종료일까지 체결되지 않은 예산은 원금에 넣지 않는다.
- DCA와 리밸런싱은 시작일의 N번째 요일 달력을 유지한다. 실제 체결 지연이 이후 일정을
  바꾸지 않는다. 밀린 납입이 여러 회차면 다음 실제 관측일에 체결한다.
- 종목별 평가액·손익·거래 로그는 전체 시뮬레이션의 USD 기록을 재사용한다.
  리밸런싱으로 다른 자산에서 넘어온 돈을 투자 수익으로 세지 않는다.
- `Total_Return`은 실제 총 납입액 대비 순손익, `Annual_Return`은 납입을 제외한 TWR CAGR이다.
  `Initial_Value`는 이름을 유지하되 실제 총 납입액이다. 콘솔 리포트는 ‘총 납입금’으로 표시한다.
- Sharpe는 무위험 수익률 0%, 252거래일을 가정한다. 변동성이 사실상 0이면 0을 반환하는
  기존 정책을 유지한다. [원 정의](https://web.stanford.edu/~wfsharpe/art/sr/sr.htm).
- 주가의 과거 값만 ffill한다. 환율도 과거 관측값만 사용하며, 누락·0·음수·무한대는
  동등 환율 1로 대체하지 않는다. 통화 정보가 없으면 USD로 추정하지 않는다.
- 기존 기술 전략의 진입 수수료 모델(`spread`, `finalize_trades`)은 유지했다.

## API와 콘솔 영향

계산 POST 하나와 조회 GET 네 개, 요청 필드와 인증 헤더는 유지한다. Turnstile 검증,
슬롯 제한, 취소 전파, 캐시·DB 구조를 변경하지 않았다. DB 마이그레이션이나 새 시크릿은 없다.

`individual_returns`에는 실제 `final_value`, `trades`, `sharpe_ratio`가 추가된다.
기존 `individual_results.final_equity`는 별도의 가상 재계산 대신 실제 종목 평가액이다.
가격은 USD로 통일하고 `start_price`는 실제 BUY 수량으로 가중한 평균 매수가다.
DCA 회차와 구성 금액은 실제 실행·납입 기준이다. 보합 연속일, Sharpe, 수수료·환율·휴장
영향을 받는 과거 결과는 의도적으로 달라진다. 나머지 일시불 평가금·기존 주요 수익률은 유지된다.

## 로컬 Docker 검증

- 기존 오류 8개를 수정 전에 실패시켰다. 추가한 독립 회귀 테스트는 총 21개다.
- BE: 단위 579개 + HTTP golden master 1개 통과. 통계의 의도된 차이를 검토하고
  응답 스냅샷을 명시적으로 재생성한 뒤 재생성 옵션 없이 다시 통과했다.
- 콘솔: 367개, ESLint, 앱/테스트 TypeScript 검사, runtime 빌드 통과.
- 의존성 감사에 예외를 추가하지 않았다. initdb와 Alembic 스키마 정합성 통과.
- 별도 MySQL·BE·FE 컨테이너의 실제 HTTP에서 6개 전략, 휴장일 DCA 두 사례,
  USD·KRW·현금+리밸런싱, 개별 평가액/손익 합계 정합성을 확인했다.
- 네 GET 병렬 조회·자료별 필드 분리·현금 1500 보존·이전 aggregate GET 제거도 확인했다.
- 실제 로컬 웹 입력으로 고정가·수수료 0·휴장일 DCA를 실행해 수익률 0%, 매수 3회를 확인했다.
- 로컬 전용 합성 데이터만 사용했다. 계산 런타임의 인증 비활성화는 로컬 개발 설정이며,
  운영의 Turnstile 인증을 끄거나 운영 비밀키를 테스트 이미지에 넣지 않았다.

## 성능 비교

동일 호스트에서 이전 이미지와 수정 이미지를 순차 실행했다. 각 컨테이너는 linux/amd64,
2 CPU·2GiB·네트워크 없음이며, 각 사례 3회 중앙값이다. 합성 OHLC와 USD 메타데이터만
주입하고 실제 전략·시뮬레이션·응답 조립·JSON 호환 변환을 실행했다.
DB·Yahoo 네트워크·Turnstile·HTTP 전송 시간과 운영 동시 처리 용량을 측정한 값은 아니다.
