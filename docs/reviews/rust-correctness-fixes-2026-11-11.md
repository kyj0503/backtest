# Rust 백테스트 16개 결함 수정과 독립 재검증

2026-11-11 감사에서 발견한 F01~F16을 모두 수정했다. 수정 승인 기준은 Python 결과 일치가 아니라 체결 인과성, 수수료 원장, 납입 예산 보존, 독립적으로 계산한 수익·위험 지표다. 합성 시나리오 **133개 / 산술·불변식 검사 202개가 전부 통과**했다. 실제 MySQL, 최종 이미지의 HTTP, 실제 브라우저의 입력·다운로드 경로도 확인했다.

수정 전 [감사](rust-adversarial-audit-2026-11-11.md)와 [당시 증거](../../comparison/adversarial/evidence-2026-11-11.json)는 보존했다. 최신 결과는 [수정 증거](../../comparison/adversarial/corrected-evidence-2026-11-11.json), 원시 출력·로그·DB 백업은 `.comparison/reports/corrected-2026-11-11/`에 있다.

최초 수수료를 납입 전 원금 대비 낙폭에 포함하는 처리도 보강했다. API 필드 `Total_Trading_Days`는 호환성을 위해 유지하며 현재 의미는 달력 평가일 수다. 새 화면과 내보내기는 이를 평가일로 표시한다. 상세 계약은 [마이그레이션 문서](../rust-migration.md)에 있다.

비중 DCA의 실제 폼 검증 중 확인한 데스크톱 총예산 편집칸 숨김도 함께 수정했다. 12,000→10,000으로 편집한 뒤 전송 예산·회당 금액·실제 납입금을 대사했다.

## 검증 범위

- Rust Docker: fmt, Clippy `-D warnings`, 일반 테스트 24개 통과. 여기에는 새 정확성 테스트 8개와 보존된 70개 입력을 독립 불변식으로 검사하는 테스트 2개가 포함된다. Python 기대 결과 파일은 재생성하지 않았다.
- 별도 MySQL 8.4: 정밀도·스냅샷 갱신·품질 검사와 부모/자식 롤백 검사 2개 통과. Alembic 전체 이력 적용 결과와 `schema.sql`의 3개 테이블 일치.
- 최종 Rust 이미지 HTTP: 금융 사례 9개, 잘못된 입력 5개, 참고 조회 4개, liveness 1개로 총 19개. 모든 상태 코드와 독립 금융 기대값 통과.
- 프론트엔드 Docker: ESLint, 앱·테스트 TypeScript, Vitest **371개 통과**. 실제 reducer·집계·CSV 및 컴포넌트 마커 콜백 추가 검증 통과.
- Chromium: 원본 화면 3개, 최종 Rust 화면 4개 시나리오. 미국주식, 한국주식 SMA, 금액 DCA, Rust 비중 DCA의 폼 제출·계산·4개 참고 조회·CSV 다운로드 검증. 비중 DCA는 전송된 총예산과 실제 납입금 10,000까지 대사한다.
- RustSec와 npm 감사 게이트, 양쪽 운영 이미지 빌드 통과. 운영 배포·커밋·푸시는 수행하지 않았다.

## 성능과 메모리

**동일한 공개 시세 스냅샷 17종목, 동일 요청 32종류, 구현별 346건**으로 측정했다. 32종류를 각각 10회 순차 실행한 뒤 미국 5종목 8년 입력으로 동시 요청 2·8·16건을 실행했다. 총 **692/692건 HTTP 200**이다. 별도로 64개 응답의 성공 상태·유한 자산·요청 종목 포함을 확인했다.

두 API 모두 2 CPU·2 GiB 제한, 단일 서버 프로세스다. Python 원본 이미지의 계산 코드는 변경하지 않고 벤치마크 컨테이너에만 고정 시세 공급 어댑터를 주입했다. Rust도 같은 파일의 시세를 사용했다. 시세 다운로드와 DB 접근을 제외한 HTTP 검증·데이터 변환·계산·직렬화 비용이다. 언어 자체만의 속도 비교나 실제 인터넷 지연을 포함한 서비스 응답시간으로 해석하지 않는다.

순차 요청 중앙값 기준 Rust는 **24.0배 빠르고**, 커널 기록 최대 컨테이너 메모리는 **68.1% 적었다**. 메모리 수집기는 다른 cgroup에서 실행해 관측기 자체 사용량을 제외했다. 1ms 주기로 요청했고 실제 간격 중앙값은 Python 1.33ms, Rust 1.35ms다. 시나리오별 샘플 최대치는 하한이며 `memory.peak`는 커널의 컨테이너 생애 최대치다. RSS는 공유 매핑 포함 방식이 달라 cgroup 수치와 동일하지 않다. 이 표는 API 프로세스 비용이며 React 개발 서버와 MySQL은 제외했다.

계산 정의가 수정되어 최종 자산·거래 수·달력 데이터 수는 Python과 다를 수 있다. 동일한 입력을 처리하는 현재 구현의 차이를 측정했다. 기존 네트워크/DB 포함 벤치마크와 조건이 달라 수치만으로 전후 성능 향상을 주장하지 않는다. 같은 PC의 다른 유휴 서비스는 유지했으며 전용 벤치마크 호스트가 아니다. 짧은 반복 측정은 장시간 메모리 누수 검증을 대신하지 않는다.

- Python 화면: http://localhost:5173 / API: http://localhost:8000
- 수정 Rust 화면: http://localhost:5174 / API: http://localhost:8001

두 저장소는 `rust-migration` 브랜치다. 비교용 Rust DB를 SQL로 백업한 뒤 이전 Alembic 스키마와 실제 구조를 대사하고 `6f903c2a711b`로 마이그레이션했다. 기존 볼륨을 초기화하지 않았고 Python 비교 DB에는 마이그레이션을 적용하지 않았다. 임시 검증·벤치마크 컨테이너는 종료하고 비교용 4개 서비스와 2개 DB를 유지한다.

## 계산 해석과 남은 범위

독립 검사 통과는 이 16개 결함의 재현 사례와 명시한 계산 계약에 대한 결과다. 모든 시장 상황의 정확성을 증명한 것은 아니다. 일봉의 수정 OHLC를 사용하고 세금·슬리피지·시장 충격·틱 단위 체결은 모델링하지 않는다. 기술 지표의 워밍업·EMA/MACD 변형과 완전 평탄 RSI=50은 명시적 모델 선택이다. 시가 거래의 외화 환산에 같은 날짜의 일간 환율을 쓰는 시간 해상도 한계도 남는다. 모든 기업행위·실시간 제공업체 데이터의 정확성을 보장하지 않는다.

기존 TODO의 계산 불가 지표 전체 정리(A-21), 장기 공백/월간 샘플링 정책(A-30), 실제 Naver 인증·OCI TLS·ARM64 운영 실행 등은 이 16개 수정의 완료로 간주하지 않는다. 달력 일간 수익률의 √365 연율화는 관측 빈도를 일치시키는 선택이며 자기상관 등까지 보정한 미래 위험 예측은 아니다.

현금흐름을 구분한 하위 기간 수익률의 기하 연결은 [GIPS 계산 방법 설명](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)과 대조했다. RSI 평균 초기화와 Wilder 갱신은 [TA-Lib 구현](https://github.com/TA-Lib/ta-lib/blob/main/ta_codegen/input/rsi/rsi.c)을 참고했다. 이 서비스가 GIPS 인증을 받았거나 모든 TA-Lib 경계값과 동일하다는 의미는 아니다.
