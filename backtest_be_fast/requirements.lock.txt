# P2-22: 완전 고정 락 파일 — requirements.txt(사람이 편집하는 입력)의 모든
# 직접/전이 의존성을 정확한 버전으로 고정한다. Dockerfile / Dockerfile.dev의
# builder 스테이지는 requirements.txt가 아니라 이 파일을 설치한다.
#
# 생성 방법: pip-compile(pip-tools) 대신, 현재 동작 중인 개발 컨테이너의
# `pip freeze`를 소스 오브 트루스로 사용했다 (189개 unit 테스트가 실제로
# 통과하는 조합이므로) —
#   docker compose -f compose.dev.yaml exec -T backtest-be-fast pip freeze
# 그 출력(런타임+테스트 의존성 혼재)에서, requirements.txt의 각 패키지가
# 선언한 Requires를 importlib.metadata로 재귀 추적하고 `pip show`의
# Required-by로 교차 검증해 "런타임에 실제로 필요한" 패키지만 추렸다
# (테스트 전용 — pytest/httpx/faker/factory-boy/freezegun 및 이들의 전이
# 의존성 — 은 requirements-test.lock.txt로 분리했다).
#
# frozendict는 예외: `pip show frozendict`의 Required-by가 비어 있어(현재
# yfinance==1.5.2의 선언 메타데이터에는 없음) 정적 추적으로는 안 걸리지만,
# 개발 컨테이너에 실제로 설치돼 있고 yfinance 내부에서 비공식적으로 참조될
# 가능성을 배제할 수 없어 안전 쪽으로 유지했다 (제거보다 여분 패키지 하나가
# 훨씬 저렴하다).
#
# 재생성: `docker compose -f compose.dev.yaml exec -T backtest-be-fast pip freeze`
# 를 다시 떠서 requirements.txt에 선언된 패키지들의 의존성 클로저만 갱신한다.
# CRITICAL: backtesting==0.3.3 / bokeh==2.4.3 / numpy<2 는 backtesting.py 0.3.3의
# 강제 요구사항이다 — 메이저 버전을 올리지 말 것 (CLAUDE.md 제약 #2 참고).
#
